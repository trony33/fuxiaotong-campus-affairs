# Alpha 测试计划与当前测试报告

> 本文采用风险驱动方式区分“已经执行的离线原型测试”和“仍待实现/执行的后端测试”。没有执行证据的项目保持为待测，不以计划代替结果。

## 1. 范围与假设

### 已有范围

- 本地离线原型：导航、政策筛选/搜索、收藏、问答、来源弹窗、材料清单、提醒、画像、管理端示例和 localStorage 持久化。
- 响应式布局：320、390、760、768、1024、1440px。
- 文档构建：系统设计书、数据库设计书和静态图示的可读性检查。

### 尚未覆盖

- 真实后端 API、数据库事务、认证/授权和多用户隔离。
- 实时政策抓取、模型调用、超时重试、限流、并发和部署恢复。
- 真实学校审批系统、通知渠道和生产数据。

## 4. 测试结论

当前证据支持“离线原型可演示、设计材料可复核”的结论，不支持“后端 Alpha 已可发布”或“政策事实已全部核验”的结论。若要将发布状态提升为“可发布”，必须先完成 API、权限、数据一致性和真实政策核验的阻塞项，或在 release 中明确其仍是 prototype/design package。
