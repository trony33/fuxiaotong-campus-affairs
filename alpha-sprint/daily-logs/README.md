# 每日日志

本目录用于保存 14 天站立会议后的简短日志。日志不是流水账，每天至少要能回答：完成了什么、下一步是什么、有什么阻塞、如何验证。当前文件为结构化模板；没有实际会议证据的日期不得写成“已完成”。
