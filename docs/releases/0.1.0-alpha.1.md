# v0.1.0-alpha.1｜Alpha 冲刺材料基线

发布日期：2026-11-12

## 本版本目的

建立奶娃工程 Alpha 冲刺的可复核 GitHub 交付基线，为 14 天开发、测试、答辩和博客提交提供统一入口。

## 包含内容

- `alpha-sprint/sprint-plan.md`：冲刺目标、改进方案、14 天节奏和工作量登记表。
- `alpha-sprint/sprint-summary.md`：最终冲刺总结博客结构和事实边界。
- `alpha-sprint/daily-logs/`：14 天站会/开发日志模板。
- `alpha-sprint/test-plan.md`：风险驱动测试矩阵和当前证据范围。
- `alpha-sprint/vlog-script.md`：3—5 分钟 Vlog 分镜与素材清单。
- `docs/alpha-sprint-defense.pptx`：答辩 PPT 初稿。
- `scripts/validate-alpha-sprint.py`：本地和 CI 结构验证脚本。

## 验证

```bash
python scripts/validate-alpha-sprint.py
```

严格提交门禁在团队补齐成员确认、真实工时、会议证据、实际燃尽图、Vlog 链接和博客链接后运行：

```bash
python scripts/validate-alpha-sprint.py --strict
```

## 范围声明

本版本不声称已经完成真实后端、实时政策检索、学校审批对接或通知服务。原型和测试报告中的 PASS 仅代表相应离线原型/文档检查范围。
